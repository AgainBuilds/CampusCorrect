# CampusCorrect

Get ahead academically with less stress.

CampusCorrect is a mobile-first academic resource platform, starting with Federal University Otuoke (FUO).

## Phase 1 Foundation

This first build provides:

- Mobile-first academic landing page
- FUO programme/level/semester selection
- Course/resource database models
- Community upload moderation queue
- Pledge gate before resource access
- Cloud-storage abstraction for PDFs/files
- Email notification abstraction for unfinished resources
- Reserved architecture for future Nigeria-wide student chat
- Render deployment configuration

## Stack

- Python + FastAPI
- SQLAlchemy
- PostgreSQL
- Jinja2 templates + vanilla JavaScript/CSS
- S3-compatible object storage for PDFs
- Render for hosting
